# AI-System-Hub

**Мета-агент на Claude, який створює та керує під-агентами з різними персонами.**

Опиши людською мовою, кого ти хочеш створити («блогер про подорожі», «бізнесмен
для пітчу стартапу», «ньюсмейкер»), — і мета-агент сам спроєктує під-агента:
підбере персону, складе системний промпт і сформулює мету. Далі ти спілкуєшся з
кожним під-агентом у простій веб-панелі.

## Можливості

- 🧠 **Мета-агент (оркестратор)** — проєктує специфікацію під-агента за твоєю
  інструкцією (у реальному режимі — через структурований вихід Claude).
- 🎭 **Бібліотека персон** — бізнесмен, ньюсмейкер, блогер, аналітик, креативник
  (легко розширюється у `src/personas.ts`).
- 💬 **Веб-панель** — список агентів, створення одним рядком, чат зі стрімінгом.
- 🧪 **Мок-режим** — без ключа API система працює на заглушках, щоб одразу
  запуститись і потестувати інтерфейс без витрат.

## Стек

- TypeScript + Node.js (вбудований `node:http`, без важких фреймворків)
- [`@anthropic-ai/sdk`](https://www.npmjs.com/package/@anthropic-ai/sdk),
  модель за замовчуванням `claude-opus-4-8` (адаптивне мислення, стрімінг)

## Запуск

```bash
npm install

# Реальний режим — задай ключ:
export ANTHROPIC_API_KEY=sk-ant-...

# Або одразу в мок-режимі (без ключа):
npm run dev
```

Відкрий <http://localhost:4317>.

### Корисні змінні середовища

| Змінна              | За замовчуванням   | Призначення                                |
| ------------------- | ------------------ | ------------------------------------------ |
| `ANTHROPIC_API_KEY` | —                  | Ключ API. Без нього — автоматичний мок-режим. |
| `AI_HUB_MODEL`      | `claude-opus-4-8`  | ID моделі Claude.                          |
| `PORT`              | `4317`             | Порт веб-сервера.                          |
| `AI_HUB_MOCK`       | —                  | `1` — примусовий мок-режим навіть із ключем. |
| `AI_HUB_MAX_TOKENS` | `4096`             | Максимум токенів на відповідь.             |

## API (коротко)

| Метод + шлях                       | Опис                                       |
| ---------------------------------- | ------------------------------------------ |
| `GET /api/status`                  | Режим (мок/реальний) і модель.             |
| `GET /api/personas`                | Список персон.                             |
| `GET /api/agents`                  | Список агентів.                            |
| `POST /api/agents/spawn`           | Мета-агент проєктує й створює під-агента.  |
| `POST /api/agents`                 | Створити агента вручну (за специфікацією). |
| `GET /api/agents/:id`              | Деталі агента.                             |
| `DELETE /api/agents/:id`           | Видалити агента.                           |
| `GET /api/agents/:id/stream?message=…` | Відповідь під-агента через SSE-стрімінг. |

## Структура

```
src/
  index.ts      — точка входу
  config.ts     — конфігурація середовища
  claude.ts     — обгортка над Anthropic SDK + мок-режим
  types.ts      — спільні типи
  personas.ts   — бібліотека персон
  metaAgent.ts  — оркестратор: проєктування під-агентів
  subAgent.ts   — діалог під-агента в межах персони
  store.ts      — in-memory сховище агентів і розмов
  server.ts     — HTTP-сервер, REST API, SSE, статика
  web/          — веб-панель (HTML/CSS/JS)
```

> Дані живуть у пам'яті процесу. Це каркас — сховище легко замінити на БД,
> не змінюючи інтерфейс `store.ts`.
