# CLAUDE.md

Настанови для ШІ-асистентів (Claude Code та інших), які працюють у цьому репозиторії.

## Що це за проєкт

`AI-System-Hub` — це **мета-агент на базі Claude**, який за інструкцією людини
проєктує та керує під-агентами з різними персонами (бізнесмен, ньюсмейкер,
блогер, аналітик, креативник тощо). Є проста веб-панель для створення агентів і
спілкування з ними.

> **Зміна стека.** Спочатку репозиторій був каркасом AL / Business Central (про
> це й досі свідчить верхня частина `.gitignore`). Тепер це проєкт **TypeScript +
> Node.js**. Якщо стек знову зміниться — онови цей файл у тій самій зміні.

## Стек та інструментарій

- **Мова:** TypeScript (ESM, `module`/`moduleResolution`: `NodeNext`).
- **Середовище виконання:** Node.js ≥ 20; HTTP — вбудований `node:http` (без
  Express чи інших веб-фреймворків).
- **ШІ:** [`@anthropic-ai/sdk`](https://www.npmjs.com/package/@anthropic-ai/sdk).
  Модель за замовчуванням — `claude-opus-4-8`. Використовуємо адаптивне мислення
  (`thinking: { type: "adaptive" }`) і стрімінг для довгих відповідей.
- **Запуск у розробці:** `tsx` (без попередньої компіляції).

## Команди

```bash
npm install        # встановити залежності
npm run dev        # запуск з гарячим перезавантаженням (tsx watch)
npm run start      # звичайний запуск через tsx
npm run typecheck  # перевірка типів без емісії
npm run build      # компіляція в dist/ + копіювання src/web → dist/web
npm run serve      # запуск зібраної версії (node dist/index.js)
```

Веб-панель: <http://localhost:4317> (порт змінюється через `PORT`).

## Режими роботи

- **Реальний режим** — якщо задано `ANTHROPIC_API_KEY`. Викликається справжній Claude.
- **Мок-режим** — якщо ключа немає або задано `AI_HUB_MOCK=1`. Повертаються
  детерміновані заглушки; мережа й API не задіюються. Зручно для розробки UI та
  тестів без витрат. Уся логіка ізоляції режиму — в `src/claude.ts`.

## Структура коду

- `src/index.ts` — точка входу (запускає сервер).
- `src/config.ts` — конфігурація із env (модель, порт, мок-режим, ліміти).
- `src/claude.ts` — обгортка над Anthropic SDK: `generate`, `stream`,
  `generateJSON` + фолбек на заглушки в мок-режимі.
- `src/types.ts` — спільні типи (`Agent`, `AgentSpec`, `ChatMessage`, `PersonaTemplate`).
- `src/personas.ts` — бібліотека персон (ключ, емодзі, базовий системний промпт).
- `src/metaAgent.ts` — оркестратор: проєктує `AgentSpec` (структурований вихід
  Claude або евристика в мок-режимі) і створює під-агентів.
- `src/subAgent.ts` — діалог під-агента в межах його персони та мети.
- `src/store.ts` — in-memory сховище агентів і розмов (легко замінити на БД).
- `src/server.ts` — HTTP-сервер: REST API, SSE-стрімінг, статика.
- `src/web/` — веб-панель (`index.html`, `styles.css`, `app.js`).

## Домовленості для ШІ-асистентів

- **Перевіряй файли перед діями.** Не припускай наявності структури — звіряйся з
  робочим деревом.
- **Мова інтерфейсу — українська.** Системні промпти, текст веб-панелі, описи
  персон і повідомлення про помилки — українською. Ідентифікатори в коді —
  англійською (ідіоматично для TS); коментарі — українською.
- **Моделі Claude.** За замовчуванням `claude-opus-4-8`. Не занижуй модель без
  явного прохання. На Opus 4.8/4.7 параметри `temperature`/`top_p`/`top_k` та
  `budget_tokens` відсутні — не додавай їх; для мислення використовуй
  `thinking: { type: "adaptive" }`.
- **Не коміть секрети** — `.env`, ключі API. `.env` уже в `.gitignore`.
- **Поважай `.gitignore`** — не додавай `node_modules/`, `dist/` тощо.
- **Тримай цей файл актуальним** — оновлюй разом зі змінами стека/структури/команд.
- **Дотримуйся стилю довкола** — наслідуй наявне форматування та іменування.
